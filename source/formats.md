# 来源资料格式

`GET /catalog` 返回当前资料版及可取的数据流。对 `GET /records/{stream}` 的响应，字段间用制表符分隔，无表头，每行一个记录。同一响应最多两行；存在下一页时通过 `Link` 中的 `rel="next"` 给出。可以通过 `edition` 明确指定保留的资料版，响应的 `X-Edition` 标出实际资料版。继续标记仅对同一个资料版和筛选条件有效。条件请求用 `If-None-Match` 传响应里的 `ETag`。

下表中列号从 1 开始。`key` 严格匹配键列。`from` 和 `until` 在整数时间列上形成左闭右开的筛选，时间粒度见各流定义。记录跨范围的情况需查看相应的起止字段。

| 数据流 | 键列 | 时间列 |
| --- | --- | --- |
| windows | 1 | 3 |
| views | 1 | 3 |
| frames | 1 | 2 |
| recovered | 1 | 2 |
| blocked | 1 | 2 |
| notes | 1 | — |
| jobs | 2 | 3 |

原件可按资料中的索引编号从 `GET /media/` 下领取，音段扩展名为 `.wav`，合成图像为 `.png`。合成媒体用于检查编号与取件。观察数量、色差及释读以各业务资料所载为准。

各数据流在后继资料版未出现更新时，继续提供原记录。横杠表示当前记录没有该值。

windows: 调查窗、河段、整数分钟起止。
views: 相机、河段、可见区间，按现场有效时间；半开区间。
frames: 相机、分钟、图号、可辨时鸟只数，逐相机每页最多两个；blocked: 相机、起止、现场记事号。
notes: 画面编号、批注号、纠正只数。
jobs: 工单、调查窗、起止、状态、已回报的只数或 -。
每行画面只证明对应的一分钟，单图批注不改变覆盖，有现场遮挡记录的相机图不能证明该分钟覆盖。
